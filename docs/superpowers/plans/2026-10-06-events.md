# Events Implementation Plan (Step 2 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed-in host can create open play events from the hub, take bookings and payments on an event page, approve or decline join requests, and share a public booking page. Everything lives under the account, not under a club session.

**Architecture:** Events are documents at `accounts/{uid}/events/{eventId}` (attendees array on the event, join requests in a `requests` subcollection). The event doc is publicly readable (the booking page lists it); join requests are private except for a validated public create and a single read by random id. The booking logic and UI already built for the quick session (`utils/bookings.js`, `BookingModal`, the attendee and payment rows) move over; the old club-session booking code is deleted. Routes `/host` and `/event/:id` are added to `AccountApp`; the public page becomes `/open-play?host={uid}`.

**Tech Stack:** React 19, Vite, Firebase Auth + Firestore, lucide-react, Firestore emulator + `@firebase/rules-unit-testing` (already set up by step 1).

**Spec:** `docs/superpowers/specs/2026-10-06-accounts-and-events-design.md` (build-order step 2). Builds on branch `feat/accounts-hub` at commit `3ee3f0b` (accounts, hub, quick session at `/club`).

## Global Constraints

- Every color is a token on `:root` in `src/styles.css` (`var(--accent)` etc.). Never raw hex. (CLAUDE.md)
- No avatar-initial badges next to names. Plain names only.
- Money shows through `money()`, times through `formatHM` / `formatDay` in `utils/format.js`.
- Phone numbers stay in the private request doc. They are never copied onto the public event doc.
- No new dependencies. No router library.
- Copy: sentence case, active voice, errors say what went wrong and what to do. One name per action across screens ("Approve", "Decline", "Delete").
- Firestore reads of the quick session (`sessions/**`) are unchanged. The only change to `sessions/**` rules is removing the old public booking-request create/get (nothing creates them any more).
- Commit steps assume you have approved committing. End commit messages with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

Inputs and conditions the spec implies but the happy path will not exercise, most likely first:

1. **A stranger reading phone numbers.** Anyone can read events; nobody but the owner may list join requests, and no phone number is ever on the event doc. Pinned by the rules test (Task 1).
2. **Joining an event that was deleted, or that never existed.** The request create must be refused, and a player whose event was deleted must see "no longer listed", not a broken page. Pinned by the rules test (Task 1) and `bookings.check.mjs` (Task 3).
3. **Deleting the account leaves nothing behind.** Roster, events, and every event's requests are gone, with no orphan subcollection docs holding phone numbers. Pinned by `tests/cascade.test.mjs` (Task 2).
4. **Time zones.** An event stores its own time zone; the public page decides upcoming vs past with that zone, not the visitor's, and an event with no zone falls back instead of throwing. Pinned by `bookings.check.mjs` (Task 3).
5. **Deep links.** `/event/<id>` while signed out lands on that event after sign-in; an unknown event id shows a clear "not found" with a way back, not a blank page. Pinned by `route.check.mjs` (Task 3) and the browser checks in Task 6.

```js
import { getDocs, limit, query, writeBatch } from "firebase/firestore";

// Deletes every document in a collection. Firestore batches cap at 500 writes, so
// go in rounds until it's empty. The db is passed in so this also runs in tests.
export async function wipeCollection(db, colRef) {
  for (;;) {
    const snap = await getDocs(query(colRef, limit(400)));
    if (snap.empty) return;
    const batch = writeBatch(db);
    snap.forEach((d) => batch.delete(d.ref));
    await batch.commit();
  }
}
```

Create `src/utils/accountData.js`:

```js
import { collection, doc, getDocs, writeBatch } from "firebase/firestore";
import { wipeCollection } from "./wipe";

// Subcollections under each event. Step 3 adds players, courts, matchLog and costs.
export const EVENT_SUBCOLLECTIONS = ["requests"];

// Erases everything an account owns: each event's subcollections first (they would
// otherwise be orphaned when the event doc goes), then events, roster, and the
// account doc itself. Data first; the caller deletes the sign-in last.
export async function deleteAccountData(db, uid) {
  const events = await getDocs(collection(db, "accounts", uid, "events"));
  for (const e of events.docs) {
    for (const name of EVENT_SUBCOLLECTIONS) await wipeCollection(db, collection(e.ref, name));
  }
  await wipeCollection(db, collection(db, "accounts", uid, "events"));
  await wipeCollection(db, collection(db, "accounts", uid, "roster"));
  const batch = writeBatch(db);
  batch.delete(doc(db, "accounts", uid));
  await batch.commit();
}
```

```js
import { useEffect, useState } from "react";
import { collection, onSnapshot, orderBy, query } from "firebase/firestore";
import { db, firebaseConfigured } from "../firebase";

// Every event of a host, soonest first. Events are public to read, so the public
// booking page uses this too. `ready` flips once the first snapshot (or error) lands.
export function useEvents(uid) {
  const [state, setState] = useState({ events: [], ready: false });
  useEffect(() => {
    setState({ events: [], ready: false });
    if (!firebaseConfigured || !uid) return;
    return onSnapshot(
      query(collection(db, "accounts", uid, "events"), orderBy("date")),
      (s) => setState({ events: s.docs.map((d) => ({ id: d.id, ...d.data() })), ready: true }),
      () => setState({ events: [], ready: true }),
    );
  }, [uid]);
  return state;
}

// Join requests per event, as { [eventId]: request[] }. Only the host can list them.
// One listener per event id; pass only the events whose requests are on screen.
export function useEventRequests(uid, eventIds) {
  const [byEvent, setByEvent] = useState({});
  const key = eventIds.join(",");
  useEffect(() => {
    setByEvent({});
    if (!firebaseConfigured || !uid || !key) return;
    const unsubs = key.split(",").map((eid) => onSnapshot(
      query(collection(db, "accounts", uid, "events", eid, "requests"), orderBy("createdAt")),
      (s) => setByEvent((cur) => ({ ...cur, [eid]: s.docs.map((d) => ({ id: d.id, ...d.data() })) })),
      () => {},
    ));
    return () => unsubs.forEach((u) => u());
  }, [uid, key]);
  return byEvent;
}
```

```js
import { addDoc, collection, deleteDoc, doc, updateDoc, writeBatch } from "firebase/firestore";
import { db } from "../firebase";
import { addAttendee, splitAttendees } from "../utils/bookings";
import { EVENT_SUBCOLLECTIONS } from "../utils/accountData";
import { wipeCollection } from "../utils/wipe";

const norm = (s) => s.trim().toLowerCase();

// Every write a host can make to an event. The signed-in account owns all of these;
// players only ever create a pending request (public page), never touch an event.
// ponytail: attendees is one array updated read-modify-write, so two tabs editing the
// same event at once can overwrite each other. Fine for one host; move to per-attendee
// docs if staff accounts arrive.
export function useEventActions({ uid, events, hostName, timeZone, notify }) {
  const eventsCol = () => collection(db, "accounts", uid, "events");
  const eventRef = (id) => doc(db, "accounts", uid, "events", id);
  const requestRef = (eventId, requestId) => doc(db, "accounts", uid, "events", eventId, "requests", requestId);
  const find = (id) => events.find((e) => e.id === id);
  const setAttendees = (id, attendees) => updateDoc(eventRef(id), { attendees });

  // hostName and timeZone are copied onto the event so the public page can show them
  // without reading the private account doc. Renaming the club later doesn't rewrite old events.
  const save = async (id, data) => {
    if (id) {
      await updateDoc(eventRef(id), data);
      notify("Open play updated.");
      return id;
    }
    const created = await addDoc(eventsCol(), {
      ...data, attendees: [], status: "scheduled", hostName, timeZone, createdAt: Date.now(),
    });
    notify("Open play created.");
    return created.id;
  };

  // Requests live under the event, so wipe them before the event doc goes.
  const remove = async (id) => {
    for (const name of EVENT_SUBCOLLECTIONS) await wipeCollection(db, collection(eventRef(id), name));
    await deleteDoc(eventRef(id));
    notify("Open play deleted.");
  };

  const add = async (eventId, name) => {
    const e = find(eventId);
    const clean = name.trim();
    if (!e || !clean) return;
    if ((e.attendees || []).some((a) => norm(a.name) === norm(clean))) return notify(`${clean} is already on the list.`);
    const attendee = { id: crypto.randomUUID(), name: clean, paid: "unpaid", method: "cash", joinedAt: Date.now() };
    const next = addAttendee(e.attendees || [], attendee);
    await setAttendees(eventId, next);
    const waiting = splitAttendees({ ...e, attendees: next }).waitlist.some((a) => a.id === attendee.id);
    notify(waiting ? `${clean} is on the waitlist.` : `${clean} added.`);
  };

  const patch = (eventId, attendeeId, change) => {
    const e = find(eventId);
    return setAttendees(eventId, e.attendees.map((a) => (a.id === attendeeId ? { ...a, ...change } : a)));
  };

  const setPaid = (eventId, attendeeId, paid) =>
    patch(eventId, attendeeId, { paid, ...(paid === "paid" ? { paidAt: Date.now() } : {}) });

  const kick = async (eventId, attendeeId) => {
    const e = find(eventId);
    const before = splitAttendees(e).confirmed.map((a) => a.id);
    const next = e.attendees.filter((a) => a.id !== attendeeId);
    const promoted = splitAttendees({ ...e, attendees: next }).confirmed.find((a) => !before.includes(a.id));
    await setAttendees(eventId, next);
    notify(promoted ? `${promoted.name} moved up from the waitlist.` : "Removed from the list.");
  };

  // The attendee id is the request id, so the player's own page can find their seat.
  const approve = async (eventId, request) => {
    const e = find(eventId);
    if (!e) return notify("That open play no longer exists.");
    const attendee = {
      id: request.id, name: request.name, method: request.method, paid: "unpaid", joinedAt: request.createdAt,
      ...(request.ref ? { ref: request.ref } : {}),
    };
    const next = addAttendee((e.attendees || []).filter((a) => a.id !== request.id), attendee);
    const batch = writeBatch(db);
    batch.update(eventRef(eventId), { attendees: next });
    batch.update(requestRef(eventId, request.id), { status: "approved" });
    await batch.commit();
    const waiting = splitAttendees({ ...e, attendees: next }).waitlist.some((a) => a.id === request.id);
    notify(waiting ? `${request.name} approved, on the waitlist.` : `${request.name} confirmed.`);
  };

  const decline = async (eventId, request) => {
    await updateDoc(requestRef(eventId, request.id), { status: "declined" });
    notify(`${request.name} declined.`);
  };

  return { save, remove, add, setPaid, patch, kick, approve, decline };
}
```

```jsx
function useMyRequests(hostId, mine) {
  const [status, setStatus] = useState({});
  const key = mine.map((m) => `${m.eventId}/${m.rid}`).join(",");
  useEffect(() => {
    if (!firebaseConfigured || !key) return;
    const unsubs = mine.map((m) => onSnapshot(
      requestRef(hostId, m),
      (s) => setStatus((cur) => ({ ...cur, [m.rid]: s.exists() ? s.data().status : "gone" })),
      () => {},
    ));
    return () => unsubs.forEach((u) => u());
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [hostId, key]);
  return status;

function JoinForm({ event, hostId, onSent, onCancel }) {
```

# Help Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A Help page (`/help`) for the whole system: six major features as visual guides with real screenshots (the queue section featured and in depth), minor features in words.

**Architecture:** Content is data (`src/data/help.js`); pure search and drift guards in `src/utils/help.js` + `help.check.mjs`; `views/Help.jsx` renders it in the signed-in frame; screenshots are static PNGs in `public/help/`, captured from the emulators with seeded demo data.

**Tech Stack:** React 19, node `*.check.mjs` checks, the Playwright MCP browser for screenshots.

**Spec:** `docs/superpowers/specs/2026-10-09-help-page-design.md`

## Global Constraints

- Tokens only for colors, new CSS only in `src/clubs.css`, sentence case, lucide icons, no avatar-initial badges next to names, neutral buttons/links `.outline`, `.primary` once per region.
- Commit only your own hunks (the tree holds someone else's uncommitted theme edits in `AccountApp.jsx`, `ClubApp.jsx`, `clubs.css`, ...): stage `HEAD` + your edit with `node $TEMP/stage-mine.cjs <edits.json>` and build the index tree before each commit.
- Screenshots: demo names only, no emails or real data, each under 250 KB, `width`/`height` set, `loading="lazy"`.
- Every statement about the queue must match the code (`utils/queueStatus.js`, `utils/rotationModes.js`, `DEFAULT_RULES`, `MODE_DESCRIPTIONS` in `data/constants.js`); the check below guards the numbers.

## Review Focus

1. A wrong sentence about the queue (order, estimate, win-streak cap, what each mode does).
2. A screenshot that shows a real name/email, or a missing file (the page must show the caption, not a broken image).
3. Phone layout: contents becomes a select, no horizontal scroll, images fit.
4. Search finds major and minor entries and says so when nothing matches.
5. Help is reachable from the sidebar and the account menu on every signed-in screen, and absent from the queue app, Live Board and public booking page.

- [ ] **Step 3: Implement.** `src/utils/help.js`:

```js
import { MAJOR, MINOR } from "../data/help.js";

const hay = (s) => [s.title, s.summary, ...(s.steps || []), ...(s.extra || []).flatMap((e) => [e.title, e.body]), s.body]
  .filter(Boolean).join(" ").toLowerCase();

// The sections and minor entries that mention the text (everything for empty text).
export function filterHelp(text) {
  const q = (text || "").trim().toLowerCase();
  if (!q) return { major: MAJOR, minor: MINOR };
  return { major: MAJOR.filter((s) => hay(s).includes(q)), minor: MINOR.filter((m) => hay(m).includes(q)) };
}
```

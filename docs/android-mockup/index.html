CourtWave on Android

How CourtWave would look as a downloaded Android app. The app screens are real captures of the current build at Pixel 7 size (412 × 915), shown in a phone frame with Android's status bar and gesture bar. The home-screen icon and the opening screen are drawn mockups.

Opening the app

Tap the icon, see the brand for a moment while it loads, then sign in or land on Home.

For players

Find a game, book it, and see your place in the queue on game night.

For hosts

Running the game from the court: rotation, results and scoring.

What's different in the app

The screens stay the same. These are the parts the app version changes or adds.

Full screenNo address bar or browser tabs. The status bar takes the color of the top of each screen.
Back gestureCloses the open window or menu first, then goes back one screen.
Opens without internetThe app's files ship inside it, and it offers an update when a newer version is online.
Google sign-inUses Android's account picker, because the website's pop-up doesn't work inside an app.
Share linksQR codes and links always point to courtwave.web.app, so people without the app can still open them.
Screen stays awakeOn the Live Board and while scoring, so the phone doesn't lock mid-game.

To do before the app ships

Found by the test run and a look through the code.

  1. Bigger buttons on the host dashboardMake the toolbar buttons, the score button and the swap / remove icons at least 40 px to tap.
  2. App manifest and iconsThere's no manifest yet. Add it with 192 px, 512 px and maskable icons from the CW mark, and a deep green theme color for the status bar.
  3. Room for the status bar and gesture barThe page doesn't use viewport-fit=cover or safe-area padding anywhere. An edge-to-edge app needs both, or the top bar slides under the clock.
  4. Share linksFive files build links from the current address (location.origin). Inside the app that address is https://localhost, so they must use courtwave.web.app.
  5. Google sign-inIt uses a pop-up today (signInWithPopup). The app needs the native Google sign-in plugin.
  6. Back gestureWire Android back to close the top dialog, the menu or the bell panel before leaving the screen.
